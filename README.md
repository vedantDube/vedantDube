### What I work on

I build systems that have to deal with inconsistent, real-world data — marketplace APIs with different rate limits, CFD config files with no fixed format, GitHub webhooks with real production traffic. I care more about whether something stays correct under retries and edge cases than whether the demo looks good once.

- 🔭 Currently: reconciling order/inventory state across 12+ marketplace APIs at **Cubelelo**, and building LLM-assisted tooling for OpenFOAM/CFD workflows at **FOSSEE, IIT Bombay**
- 🧠 Also into: reinforcement learning for wireless networks — first-author on an IEEE paper (under review) on RIS-assisted network optimization
- 🏆 Winner, Hack-o-Harbour 2025 (150+ teams) · Runner-up, Codeutsav 8.0 (300+ teams, NIT Raipur's largest hackathon)

### Projects I'd actually want you to look at

**[FlowOps](https://flow-ops-liard.vercel.app/)** — Engineering intelligence SaaS · [code](https://github.com/vedantDube/FlowOps)
Multi-tenant platform that ingests GitHub commits/PRs/reviews via OAuth + webhooks and surfaces real-time engineering metrics. Includes an AI review pipeline for security/anti-pattern detection, a PR automation engine that auto-approves low-risk changes and nudges stale reviews, and 4-tier RBAC with real-time updates via Socket.io.
`Next.js` `Express` `PostgreSQL/Prisma` `Docker` `GitHub OAuth`

**[CookGPT](https://cook-gpt-azure.vercel.app/)** — Multimodal RAG chatbot (1st place) · [code](https://github.com/vedantDube/Cook_GPT)
Text + image query chatbot with sub-second latency, semantic retrieval over 10,000+ embeddings via Pinecone, and Gemini-powered multimodal reasoning.
`Flask` `LangChain` `Pinecone` `React` `Clerk`

**[OpenFOAM × LLM Integration](https://github.com/FOSSEE/pyvnt_llm/tree/vedant_main)** — FOSSEE, IIT Bombay
Grammar-based parser converting 100+ inconsistent OpenFOAM case configs into structured trees, plus a RAG pipeline that maps free-form CFD comments to structured fields — 35% accuracy improvement over a regex-only baseline.
`Python` `OpenFOAM` `PyVNT` `HuggingFace`

**[Multi-Actor DRL for RIS-IAB Networks](https://github.com/vedantDube/Hybrid_RIS)** — IEEE paper, submitted/under review
First-author work combining DistilBERT and DDPG for sparse hybrid RIS-assisted networks, improving energy efficiency by 17.4–42.1%.
`MATLAB` `Reinforcement Learning`
